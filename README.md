# 角色藏馆 · 可莉与魈

手机优先的三维角色展示网页，顶部切换可莉与魈。

入口：`index.html`。旧入口 `show-xiao.html` 会跳转到统一网页的魈展台。

- 可莉：约6秒原始跑步动作及表情、播放暂停、进度拖动、变速、静态展示。
- 魈：约84秒舞蹈、原创配乐《风影舞曲·卡点版》、音乐开关、面具特写、布料动态。
- 通用：拖动旋转、双指缩放、全身/面部/背部视角、背景切换、自动环绕、线框、保存画面和全屏。

模型按选择加载，切换角色或展示模式时释放上一模型的三维资源。暂停、后台或三维区域不可见时停止持续渲染。手机降低渲染像素密度，魈的布料模拟最多每秒更新30次。

沿用仓库中已经优化的魈模型（WebP贴图）；可莉跑步模型约2.8 MB，静态模型约1 MB。首次打开只加载可莉跑步素材，魈素材和音乐在选择后加载。

部署时保留完整 `web/` 目录。GitHub Pages选择当前分支和 `/(root)` 即可；也支持仓库子目录访问。所有组件均包含在仓库中，无外部CDN依赖。

模型提供：miHoYo；魈模型改造：观海。配乐：《风影舞曲·卡点版》，原创程序合成器乐。角色来自《原神》，网页为非官方展示。

原魈素材说明限制二次配布和商业使用；使用与公开发布需遵守相应素材许可。`web/vendor/LICENSE`保留Three.js许可证。
